## 0. 三句话结论

1. **把「欧奈尔式风控」照搬到错误的买点上,会亏得更惨**(年化 −8.69%、回撤 46.1%);
   原因是 8% 止损挂在日波动 6.05% 的位置上,**只有 1.3 个标准差**。
2. **换成「波动收敛的平台边缘」买入后,框架翻身**:
   年化 **+15.83%**、最大回撤 **16.7%**、止损触发从 156 次降到 34 次。
3. **但同市值同行业随机对照拿到 +18.29%** —— **超额 −2.46pp、p = 0.656,不通过。**
   **这套东西的价值在框架(择时 + 风控),不在选股。**

## 1. 筛选器在找什么

三段结构里的**中间那一段**(强势 → 深调 → 整理 → 再拉升):

```
强势日(RPS60 进全市场前 10%)
    ↓ 至少 15 个交易日
期间触及 20 周线(MA100 × 1.03 以内),且 20 周线向上
    ↓
整理段:缩量 + 波动收敛 + 浅回调   ← 筛选器判的是这里
    ↓
突破平台上沿                      ← 买点
```

三个条件(从 20 个特征里筛出来的,全部来自调整期):

| 指标 | 定义 | 绝对阈值 |
|---|---|---|
| 缩量比 | 整理段日均成交量 ÷ 强势日前 60 日日均成交量 | **< 0.80** |
| 收敛比 | 触 20 周线后日均真实波幅 ÷ 强势日前 60 日日均真实波幅 | **< 0.80** |
| 深度 | 1 − 整理段最低价 ÷ 整理段最高价 | **≤ 0.352** |

**注意有两把尺子**:绝对阈值(上表,legacy)与「当天全市场正在整理的股票里最优 40% 分位」。
两者结果差很多 —— 19 只案例全历史:绝对尺 18 只/4,317 天,分位尺 17 只/1,130 天,
**分位尺在多数月份反而更严**。本报告全部用**绝对尺**。

## 2. 完整口径(可复现)

| 项 | 取值 |
|---|---|
| 面板 | **3,297 交易日 × 5,232 只**(2013-01-04 → 2026-08-03) |
| 价格 | 前复权收盘;**退市股按最后有效价 ffill 参与,绝不剔除** |
| 合格 | 非 ST、非停牌、上市满 250 日、当日有成交 |
| **入场** | 当日三条全中 **且** 收盘 > 平台内(强势日→**前一日**)最高收盘 → 当日收盘买入 |
| **止损** | 平台下沿(平台内→前一日最低收盘);距买入价超 15% 则上移到买入价 −15%,**取较紧的** |
| **持有上限** | 120 个交易日 |
| **大盘过滤** | 全市场等权净值 < 自身 MA200 → **当日清仓且不新开仓** |
| **仓位** | 10 个等权槽位;空槽记 0 收益(现金);突破日先到先得,同日按**收敛比升序** |
| 训练段 | 2019-01 → 2022-12(只报数) |
| 留出段 | **2023-01 → 2026-04**(判据在这里) |
| 对照 | 每次策略实际开仓的**同一天、同一槽位**,换成**同市值名次 ±25、同申万一级行业**随机股,**走完全相同的出场逻辑**(止损按同一百分比),**500 组种子** |

判据在跑之前写死并先行提交(commit `2a9da63`),跑完照判,不放宽。

## 3. 锚点(全过,其中一条抓出了一个真 bug)

| 锚点 | 实测 |
|---|---|
| 面板形状 | (3297, 5232) ✓ |
| 价格 ffill 后首价之后空洞 | 0 ✓ |
| 行业恒等式违例 | 0 ✓ |

| **宇通客车 600066 复现** | 2023-10-17→2024-01-09 **三条全中 42 天**、首次 **2023-10-17**、最后 **2024-01-09**,三个数全中 ✓ |
| **无前视** | **3,000 个真实买点**逐个断言上沿/下沿/平台起点 ✓ |

> **⚠️ 一个值得你也注意的坑**:第一版无前视断言是随机抽 (日期, 股票),
> 1,500 次只命中 **4 个**买点,**通过了**。改成从 30,446 个真实买点里抽 3,000 个,**立刻失败** ——
> 根因是平台上下沿存成了 **float32**,与 float64 收盘价比较时在「打平」处
> 把**等于**误判成**突破**。**修正后留出段年化从 +19.81% 掉到 +15.83%,那个 bug 虚增了约 4pp。**
> **弱断言会放过真 bug。**

## 4. 主判定:框架有效,选股无增量

留出段 2023-01–2026-04,零成本口径:

| | 年化 | 最大回撤 | 止损触发 |
|---|---|---|---|
| 照搬 8% 固定止损(错误买点) | **−8.69%** | 46.1% | 156 |
| **平台买点 + 平台下沿止损** | **+15.83%** | **16.7%** | **34** |
| 全市场等权(参照) | +13.58% | — | — |
| 510300 沪深300(参照) | +7.60% | — | — |
| **同市值同行业随机对照(500 组)中位** | **+18.29%** | — | — |

**判定:超额 ≥ +3.00pp ✗(−2.46pp);p < 0.05 ✗(0.6560)→ 不通过。**
训练段同样:−1.17% vs 对照 −1.68%,超额 +0.51pp。

### 买点位置的机制被证实了(这是跑之前写死的可证伪检验)

| | 错误买点 | 平台买点 | |
|---|---|---|---|
| 买入日 20 日**日波动率**中位 | 6.05% | **2.51%** | ✓ |
| 止损距买入价 ÷ 日波动率 | **1.3 σ** | **5.54 σ** | ✓ |

**同样是 8%,挂在日波动 6% 的位置上只有 1.3 个标准差 —— 那不是止损,是掷硬币。**
**这是整个研究里唯一被证实的机制性结论。**

## 6. 三个我认为对你最有用的结构性发现

### 6.1 真正在管风险的是大盘开关,不是止损

545 笔的卖出原因与结果:

| 卖出原因 | 笔数 | 占比 | 收益均值 | 胜率 | 持有中位 |
|---|---|---|---|---|---|
| **大盘过滤清仓** | **413** | **75.8%** | +1.27% | 40.2% | **5 日** |
| 止损 | 88 | 16.1% | **−15.36%** | — | 21.5 日 |
| **持有到期 120 日** | **44** | 8.1% | **+31.13%** | **81.8%** | 120 日 |

**利润全部在「持有到期」那 44 笔里:均值 +31.13%、胜率 81.8%、最大 +295.7%。**
2018 年成交 0 笔,因为大盘过滤全年关闭 —— 这是过滤器按设计工作。

### 6.2 收益极度集中在右尾

| | 合计收益 | 其余各笔合计 |
|---|---|---|
| 前 **5** 笔 | **+845.7%** | 其余 540 笔 **−303.9%** |
| 前 **10** 笔 | **+1207.5%** | 其余 535 笔 **−665.7%** |
| 前 20 笔 | +1642.5% | 其余 525 笔 −1100.8% |
| 前 50 笔 | +2372.0% | 其余 495 笔 −1830.2% |

单笔收益分位:10% −15.6% ｜ 25% −8.4% ｜ **50% −1.8%** ｜ 75% +2.9% ｜ 90% +15.3% ｜ 99% +84.5%

**前 1.8% 的交易贡献的收益,是全部收益的 2.2 倍;其余 98% 加起来是净亏的。**
**任何砍右尾的做法(止盈、缩短持有、追求高胜率)都会直接把这套东西打死。**

### 6.3 MA200 硬开关在震荡市会频繁误杀 —— 这是我发现的最值得改的一处

- 10.5 年里大盘过滤关闭了 **51 次**(51 个不同的清仓日)
- 413 笔清仓中,**52.5% 持有 ≤ 5 个交易日**,66.3% ≤ 10 个交易日
- 2026 年 6 月下旬到 7 月初,连续三次清仓(6-25 / 7-02 / 7-06),
  刚建的仓两三天就被扫掉

**这个开关同时是回撤只有 16.7% 的原因,也是半数仓位活不过一周的原因。
它很可能杀掉了一部分本会长成右尾的持仓** —— 而右尾就是全部利润。
**我没有测过带缓冲带或延迟确认的版本,这是一个明确、可测、尚未被占用的方向。**

## 7. 我可能错的地方(请你核对)

1. **对照共享了买入日。** 对照股在策略的开仓日买入,所以「什么时候买」的信息是两者共有的。
   因此本报告测的是**纯粹的选股增量**,不是整套框架的价值。
   框架本身的 +15.83% / 回撤 16.7% 是实打实的,只是它不专属于这批股票。
2. **样本量小,功效不足。** 留出段只有 **133 笔**成交,对照 5–95 分位 [+9.31%, +27.88%],
   标准差约 5.6pp。**在 p<0.05 下判定通过实际需要超额约 +9.3pp,而不是判据写的 +3.00pp
   —— 我这条判据的两个条件在这个样本量下自相不一致。**
   但点估计本身是负的(−2.46pp),连较松的那条也没够着,所以结论不受影响。
3. **退市股 ffill 处理**:退市后价格保持不变(收益 0),而非记 −100%。
   对策略与对照一视同仁,但会同时抬高两者。
4. **两把尺子。** 本报告全用绝对尺;换分位尺结论可能不同,我没跑。
5. **未纳入**:滑点、涨跌停无法成交、流动性、停牌期间的处理精度。

## 8. 建议你做的三件事

1. **别再找入场规则了。** 本项目在这条路上试过 8 个候选(两篇卖方研报、你的 X01 三档与
   统一信号、我的 4 套),**没有一个能同时通过概率口径与组合口径**。
   概率口径通过的(你的强确认 lift 1.50、我的 1.39),在组合口径全部跑输随机对照。
2. **测「大盘开关的形态」而不是「选哪只股票」。** 见 6.3:
   MA200 硬开关 52.5% 的持仓活不过 5 天。缓冲带、延迟确认、
   或换成宽基指数而非全市场等权 —— 这三个都可测且都没人做过。
3. **任何工作簿都请加两列:逐年表 + 对照组。**
   你上一版「统一信号」的合计 lift 1.47 高于我的 1.39,
   但逐年只有 5/8 年 lift>1(我的 7/8)—— **合计数字会被少数年份主导。**
