## 4. 为什么「捞到平安和寒武纪」这件事本身有问题

我查了三只目标股在**设定特征**上的位置:

| | 60日收益百分位 | `recent_volume_ratio` 百分位 | `recent_atr_ratio` 百分位 |
|---|---|---|---|
| 中国平安 | 91% | 78% | **95%** |
| 寒武纪 | **100%** | **96%** | 44% |
| 华虹公司 | 99% | 15% | 28% |

**而这两个特征与收益都是负相关**(量比 Q1 8.0%→Q5 4.5%;波幅比 Q1 8.4%→Q5 3.7%)。

**它们不是「被规则误伤的好样本」,而是「在预测性维度上本来就长得像差样本」的样本。**
用它们标定阈值 = 把「好结果」倒灌进「设定特征」。这也解释了为什么每次放宽都变差:
**放宽让「特征偏差但结果好」的个例进来,进来的其他事件只有「特征偏差」。**

## 5. 我试的另一条路:不放宽入口,收紧出口

用你 §七 提过的「突破后回踩是否守住平台上沿」:

```
确认成立 ⟺ 突破后 N 个交易日内,最低收盘 ≥ 平台上沿 × (1 − k)
入场改在确认日 t + N
```

N ∈ {5,10} × k ∈ {0,3%},四个组合全部事前登记、全部报告。

**它用的是突破日之后的信息,不是设定特征,所以不受「用结果标定设定」的污染。**

**全样本 60 日:**

| | 确认率 | 年化超额 | p |
|---|---|---|---|
| N=5 k=0% | 41.3% | −1.23pp | 0.9353 |
| N=5 k=3% | 69.7% | +0.72pp | 0.1294 |
| N=10 k=0% | 31.8% | +1.25pp | 0.0647 |
| **N=10 k=3%** | 56.4% | **+2.86pp** | 0.0050 |

**它确实在分离好坏**:通过确认的 60 日收益 **5.14%**,未通过的 **3.16%**。

**但时间样本外撑不住**(训练段 2013–21 只报数,留出段 2022–26 判据):

| | 训练段 | **留出段** |
|---|---|---|
| N=10 k=3% | **+3.84pp** / 0.0050 | **+1.60pp** / 0.0199 |
| N=10 k=0% | +1.97pp / 0.0398 | +0.33pp / 0.3284 |
| N=5 k=3% | +2.77pp / 0.0050 | −1.70pp / 0.9900 |
| N=5 k=0% | +0.92pp / 0.2786 | **−3.74pp** / 1.0000 |

**留出段 0/4 通过。** 那个 +2.86pp 是两段混出来的。

**但有两点值得你一起看**:N=10 k=3% 是唯一两段都为正的,留出段 120 日 +2.47pp
(p 0.0100)、250 日 +1.20pp(p 0.0199)也都正且 p<0.05,**方向没翻**;
且**参数排序两段完全一致**,纯噪声不会这样。

另需说明:**留出段本身对这个形态整体不友好** —— 60 日事件收益 8.09% → 0.87%,
对照 7.36% → 0.49%。
