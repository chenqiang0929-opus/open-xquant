## 1. 设计逻辑

两条都是**「同日全市场横截面 → 各分项转百分位 → 等权平均」**的合成因子,
差别在于用什么当分项。定义逐字来自 `evaluate_value_factors.py:109-115`
与 `evaluate_quality_factors.py:30-66`,我在 `route_scores()` 里照抄,没有改写。

### 1.1 R08 价值复合 `value_composite`

```python
ep  = eps_ttm   / price      # 盈利收益率
bp  = bps       / price      # 每股净资产 / 价格
cfp = ocfps_ttm / price      # 每股经营现金流 / 价格
每项:where(v > 0) → rank(pct=True, 升序) → 三项 mean(skipna=False)
```

**(a) 全部写成「收益率」形式,不是估值倍数。** 用 `E/P` 而不是 `P/E`。
这不是口味问题:市盈率在盈利趋近 0 时会爆到无穷、亏损时变负数,**排序会炸**;
倒过来写,亏损公司落在负值区间、可以被一条 `> 0` 干净切掉,正常公司分布平滑。

**(b) 三个分母同一个价格,三个分子分别是「利润 / 净资产 / 现金流」。**
从三个角度问同一句话:**这个价格买到了多少东西。** 三者互相制衡 ——
只看 `ep`,利润可被会计处理粉饰;加 `cfp`,利润好而现金流差的被扣分;
加 `bp`,轻资产高估值与重资产低估值区分开。

**(c) `where(v > 0)` 是资格门,不是过滤器。**
任一项为负或缺失 → 该项 rank 为 NaN → `mean(skipna=False)` 让**整只股票分数变 NaN**,
直接退出候选池。**这是全票通过制**:亏损、资不抵债、经营现金流为负,任一中即出局。
所以 R08 缺失率天然很高 —— **不是数据缺,是很多公司根本不合格**。

**(d) R08 没有缩尾**,因为 `> 0` 那道门已经把极端值挡在外面。

### 1.2 R09 核心质量复合 `core_quality_composite`

```python
marg = ni_ttm    / rev_ttm    资格门 marg > 0              净利率
roe  = roe_lvl                资格门 roe  > 0              净资产收益率
roec = roe_chg                资格门 ep   > 0              ROE 同比变化
conv = ocfps_ttm / eps_ttm    资格门 ep>0 & cfp>0 & conv>0 现金利润转换率
每项:资格掩码 → clip 到 [1%, 99%] 分位 → rank(pct=True) → 四项 mean(skipna=False)
```

**(a) 四项全部与价格无关。** 这是两条的根本分工:
**R08 问「贵不贵」,R09 问「好不好」,必须分开量。**
也正因不含价格,R09 完全不受复权口径影响 —— 实测两种价格口径都是 **+8.50%,差 0.00pp**。

**(b) 三个静态 + 一个动态。** 净利率、ROE、现金转换率是**水平**;ROE 同比变化是**趋势**。
只看水平会买到「好但正在变差」的公司,加一项趋势做修正。

**(c) `conv = 每股经营现金流 / 每股收益` 是四项里最狠的一条。**
它直接问:**账上赚的钱,收回来了吗?** 利润 1 块、现金流 0.1 块的公司,
前三项可能都漂亮,这一项把它打下去。资格门也最严 —— `ep>0 且 cfp>0 且自身>0` 三条同时满足。

**(d) 有 1%/99% 缩尾,R08 没有。** 因为 R09 的分项是**比率**,
ROE 同比变化尤其会出现「上年 0.1%、今年 5%」这种数千倍的异常值;`clip` 把两端拉回来再排名。

### 1.3 两条共有的关键设计:先转百分位,再平均

不是把 `ep = 0.05` 和 `roe = 12%` 直接相加(量纲不同,没意义),
而是**每一项先换算成「今天在全市场排第几百分位」,再等权平均**。

**好处**:量纲统一、抗异常值、不用调权重。

**代价 —— 也正是第 2 节结果的根源**:分数变成**纯排序信息**,
0.9 只说明「今天排前 10%」,**不含任何「好多少」的信息**。
一只 ROE 30% 和一只 ROE 15% 的公司,只要当天分别排 95% 和 94%,分数就几乎一样。
