# 平台筛选器使用说明(`consolidation_screener.py`)

**版本**:2026-08-28 ｜ **配套脚本**:`rps_pool_study/platform_pivot.py`(第一五五节买点与回测)

---

## 0. 先看这一条,别跳过

这个筛选器**没有通过随机对照检验**。

| 检验 | 结果 |
|---|---|
| 第六十一节:「三条全中」组合年化 | +10.37%,但 **300 次随机对照 p = 0.16** → 与随机无法区分 |
| 第一五五节:接上买点+止损+择时后年化 | **+15.83%**、最大回撤 **16.7%**(很漂亮) |
| 同上,对同市值同行业随机对照 | 对照拿到 **+18.29%**,**超额 −2.46pp、p = 0.656** → 不通过 |

**结论:这套东西真正有效的部分是「在波动收敛的位置买、止损放在结构位、大盘不好空仓」这个框架,
它对同类股票的任意一篮子都有效。「买哪一只」这一步测不出增量。**

**所以它的正确用法是:缩小观察范围的状态标记,不是买入信号。**

---

## 1. 它在找什么形态

三段结构里的**中间那一段**:

```
   强势段              整理段(← 筛选器找的是这里)         再拉升
   RPS60 进前 10%  →   深调到 20 周线附近,然后            突破平台上沿
                       缩量 + 波动收敛 + 浅回调
```

三个条件(第五十九节从 20 个特征里筛出来的,全部来自调整期):

| 指标 | 定义 | 含义 |
|---|---|---|
| **缩量比** | 整理段日均成交量 ÷ 强势日前 60 日日均成交量 | 越小说明抛压越干 |
| **收敛比** | 触 20 周线之后的日均真实波幅 ÷ 强势日前 60 日日均真实波幅 | 越小说明波动越收敛 |
| **深度** | 1 − 整理段最低价 ÷ 整理段最高价 | 越小说明回调越浅 |

时序还必须走完:**强势日(RPS60>90)→ 至少 15 个交易日之后 → 期间触及过 20 周线(MA100 的 1.03 倍以内)**。
走不完时序的股票直接不给分,不是给 0 分。

## 2. 两把尺子 —— 这是最容易用错的地方

脚本里有**两套阈值**,回答的是两个不同的问题:

| 尺子 | 阈值 | 回答的问题 | 默认用在 |
|---|---|---|---|
| **绝对(legacy)** | 缩量比 < 0.80、收敛比 < 0.80、深度 ≤ 0.352,调整天数 ≥ 15,且要求 20 周线向上 | 「它像不像 2014–2019 定义的那种教科书式干净整理」 | **单只回看**(`--code`) |
| **分位(adaptive)** | 三个指标各取**当天全市场正在整理的股票**里最优 40% 分位,调整天数下限自适应 | 「在**今天这批**正在整理的股票里,它排不排得进最干净一档」 | **全市场扫描**(`--date` / `--all`) |

**两把尺子的结果可以差很多。** 19 只案例股全历史实测:绝对尺 18 只亮灯、4,317 天;分位尺 17 只、1,130 天
—— 分位尺在多数月份**比 0.80 更严**。

**第一五五节用的是绝对尺(legacy)**,原因有两条:
① 宇通那个可复现锚点(42 天 / 首次 2023-10-17 / 最后 2024-01-09)是绝对尺下的数;
② 绝对阈值是固定常数,不依赖每月重算的横截面,少一条前视风险。

任何模式都能用 `--legacy` / `--adaptive` 手动切,两者互斥。

## 3. 怎么跑

### 3.1 单只回看(看某只股票历史上什么时候亮过灯)

```bash
uv run python consolidation_screener.py \
  --data /home/user/oxq-panel/oxq_stock_market_fixed \
  --code 600066 --from 2023-01-01 --to 2024-12-31 --daily
```

- `--code` 六位代码(不带交易所前缀)
- `--from` / `--to` 区间,省略则全历史
- `--daily` 逐日打印;**不加则只打印状态变化的日子**(推荐先不加,输出短)
- 默认走**绝对尺**;想用分位尺加 `--adaptive`(会慢很多,要逐月重算全市场横截面)

输出列:

```
日期        强势日        触20周线      调整天  现价   深度    缩量比  收敛比  条数
2023-10-17  2023-07-20   2023-09-27      61   11.28  0.160  0.62   0.72    3
```

**`条数 = 3` 就是「三条全中」。** 上面这一行就是宇通 2023 年那次整理的第一次亮灯。

### 3.2 全市场扫描(今天有哪些股票在干净整理中)

```bash
# 面板最后一天,输出前 30 只三条全中
uv run python consolidation_screener.py \
  --data /home/user/oxq-panel/oxq_stock_market_fixed --top 30

# 指定日期 + 落 CSV + 输出所有走完时序的股票(不只三条全中)
uv run python consolidation_screener.py \
  --data /home/user/oxq-panel/oxq_stock_market_fixed \
  --date 2026-08-03 --all --out /tmp/platform_20260803.csv
```

- 默认走**分位尺**;要和第一五五节口径一致就加 `--legacy`
- `--all` 会输出全部走完时序的股票(含只中 1、2 条的),配合 `--out` 做后续筛选
- 全市场扫一天需要遍历 5,232 只 × `score_one`,**约 1–3 分钟**

## 4. 从「亮灯」到「买点」—— 第一五五节的完整构造

**亮灯本身不是买点。** 亮灯只说明「它现在在一个干净的平台里」。买点是平台被突破的那一刻:

| 环节 | 规则 |
|---|---|
| **入场** | 当日三条全中 **且** 收盘价 > 平台内(从强势日到前一日)的**最高收盘价** → 当日收盘买入 |
| **止损** | 挂在**平台下沿**(平台内到前一日为止的**最低收盘价**);若下沿距买入价超过 15%,则上移到买入价 −15%,**取较紧的那个** |
| **持有上限** | 120 个交易日 |
| **大盘过滤** | 全市场等权净值跌破自身 MA200 → **当日清仓且不新开仓** |
| **仓位** | 10 个等权槽位;填槽按**突破日先到先得**,同日多只按**收敛比升序**(越紧凑越优先) |

跑法:

```bash
uv run python rps_pool_study/platform_pivot.py
```

它会依次打印:锚点核对 → 买点总数 → 训练段/留出段的年化、回撤、对照分布、判定,并落 `platform_pivot.csv`。

### 为什么止损要挂平台下沿,而不是固定 8%

第一五四节照搬欧奈尔的 **−8% 固定止损**,结果组合年化 **−8.69%**、回撤 46.1%、止损触发 156 次。
原因查清楚了:

| | 第一五四节(月末/新高日买) | 第一五五节(平台突破买) |
|---|---|---|
| 买入日 20 日**日波动率**中位 | **6.05%** | **2.51%** |
| 止损距买入价 ÷ 日波动率 | **1.3 σ** | **5.54 σ** |
| 止损触发次数 | 156 | **34** |

**同样是 8%,挂在日波动 6% 的位置上只有 1.3 个标准差 —— 那不是止损,是掷硬币。**
平台把波动压下去之后,同样的止损距离才变成真正的「不该发生」。

**这是整个研究里唯一被证实的机制性结论。**

## 5. 输出字段速查

| 字段 | 含义 |
|---|---|
| `强势日` | 最近一次 RPS60 进全市场前 10% 的日子,整理段从这里起算 |
| `触20周线` | 强势日之后第一次触及 MA100×1.03 的日子,收敛比从这里起算 |
| `调整天数` | 当日 − 强势日 |
| `触线后天数` | 当日 − 触线日 |
| `深度` | 1 − 整理段最低价/最高价,**越小越浅** |
| `缩量比` | **越小越干**,绝对尺门槛 < 0.80 |
| `收敛比` | **越小越收敛**,绝对尺门槛 < 0.80 |
| `距区间高` | 现价 ÷ 整理段最高价 − 1,**越接近 0 越贴近突破** |
| `条数` | 三条里中了几条,**3 = 全中** |

## 6. 用它的时候别踩这几个坑

1. **别把亮灯当买入信号。** 亮灯只是状态标记;第六十一节的随机对照 p = 0.16。
2. **别混用两把尺子。** 同一只股票在两把尺子下判定可以完全不同,做对比时必须显式指定 `--legacy` 或 `--adaptive`。
3. **别只看条数,要看`距区间高`。** 三条全中但离平台高点还有 20%,离买点还早。
4. **别用 float32 存平台上下沿。** 第一五五节在这里踩过:float32 与 float64 收盘价比较时,
   在「打平」处会把**等于**误判成**突破**,虚增留出段收益约 **4pp**。
5. **别用弱断言验无前视。** 同一节里,随机抽 (日期, 股票) 1500 次只命中 4 个买点,**通过了**;
   改成从 30,446 个真实买点里抽 3,000 个,**立刻抓到上面那个 bug**。
6. **样本量很小。** 第一五五节留出段只有 **133 笔**成交,统计功效不足以判定 +3pp 的增量。

## 7. 一句话总结

**这个筛选器帮你把 5,000 只压到每天几十只「正在干净整理」的股票,
再配上「突破买入 + 平台下沿止损 + 大盘过滤」,能得到一个年化 +15.83%、回撤只有 16.7% 的框架。**

**但同样的框架换成随机抽的同市值同行业股票,拿到 +18.29%。
所以这套东西的价值在框架,不在选股 —— 请把它当观察池工具用,不要当选股模型用。**

**本文档不构成任何投资建议。**
